# Insight Studio Design — Site Institucional

Protótipo de site institucional desenvolvido para a **Insight Studio Design (Insight SD)**, com o objetivo de fortalecer sua presença digital, apresentar seus serviços e facilitar o contato com potenciais clientes.

O projeto foi realizado como parte do **Projeto de Extensão V**, do curso de Análise e Desenvolvimento de Sistemas do Centro Universitário União das Américas Descomplica.

## Tecnologias utilizadas

- HTML5 — Estrutura e organização do conteúdo.
- CSS3 — Estilização e responsividade.
- JavaScript — Interatividade e navegação.
- Netlify — Hospedagem e publicação do protótipo.

## Funcionalidades

- Apresentação institucional da empresa.
- Seções de serviços e portfólio.
- Layout responsivo para computadores e dispositivos móveis.
- Menu de navegação adaptado para telas menores.
- Integração com WhatsApp e Instagram.
- Navegação entre as seções do site.

## Acesse o projeto

**Site publicado:** https://insightsdproto.netlify.app/

## Desenvolvimento e evolução

O projeto consiste em uma **versão preliminar funcional**, desenvolvida para atender às necessidades institucionais iniciais da empresa.

Sua estrutura permite a evolução gradual do site, com a possibilidade de incorporar novos conteúdos, projetos ao portfólio, páginas de serviços e funcionalidades conforme as demandas da Insight Studio Design.

## Como executar localmente

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Navegue pelas seções para visualizar o protótipo.
